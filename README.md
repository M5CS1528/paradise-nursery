# Paradise Nursery — Online Plant Shop

Paradise Nursery is a responsive React shopping-cart application for browsing and purchasing houseplants. It demonstrates reusable React components, React Router navigation, Redux Toolkit cart state, and dynamic quantity and price calculations.

## Features
- Landing page with company introduction and a Get Started button
- About Us page with company information
- Plant catalog with three categories and six houseplants per category
- Add-to-cart controls and a dynamic cart item count
- Shopping cart with quantity controls, delete actions, subtotals, and total cost
- Continue Shopping navigation and a Coming Soon checkout message

## Technology
- React and Vite
- React Router
- Redux Toolkit and React Redux
- CSS

## Run locally
```bash
npm install
npm run dev
```

The project is an educational demonstration; product names, prices, and images are sample catalog data.
